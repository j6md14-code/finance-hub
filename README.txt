PUBLICAÇÃO NO GITHUB
Envie/substitua os quatro arquivos na raiz do repositório finance-hub (branch main).
Mantenha os nomes exatamente como estão.

INSTALAÇÃO NO IPHONE
1. Abra o endereço publicado pelo GitHub Pages no Safari.
2. Toque em Compartilhar.
3. Escolha Adicionar à Tela de Início.
4. Confirme o nome Nexo e toque em Adicionar.

IMPORTANTE
O botão Sair e a escolha João/Laura nesta versão são apenas uma navegação demonstrativa.
Ainda não substituem autenticação real do Supabase. Não utilize dados financeiros reais
até a integração de autenticação, persistência e políticas RLS estar concluída e testada.
